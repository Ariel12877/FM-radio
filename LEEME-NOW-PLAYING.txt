RADIO ARGENTINA — EDICIÓN SIN TAGS, CON PERRITO BAILARÍN

CAMBIOS
- Se eliminó por completo el visor de tags, la lectura ICY/JSON y la búsqueda externa de canciones.
- Se quitó now-playing.js y sus conexiones desde app.js e index.html.
- Se agregó una mascota animada con emojis musicales y bailarina.
- El perrito se desplaza de izquierda a derecha y el propio GIF tiene poses de baile.
- Se conservaron la lista de emisoras, las URLs de streaming y la lógica de Play/Pausa.
- Se mantienen los ajustes compactos de dial y controles realizados en la versión anterior.

POR QUÉ ANTES NO SE VEÍA EL PERRITO
La imagen generada era un GIF animado de 9 fotogramas completo. La versión anterior lo trató equivocadamente como si fuera una cuadrícula de 3 x 3 y recortó cada fotograma en nueve pedazos. El resultado era una imagen recortada que no mostraba al perro entero. Esta versión usa el GIF original completo, sin trocearlo.

COMPATIBILIDAD
- Se utiliza GIF animado, formato ampliamente admitido por navegadores móviles Android, y CSS estándar para el desplazamiento.
- No se utiliza WebP animado, canvas, Web Audio ni APIs experimentales para mostrar la mascota.
- El archivo está guardado localmente en assets/radio-dog-dance.gif y se precarga en el Service Worker; no depende de un servidor de imágenes externo.
- Si el navegador bloquea animaciones por una preferencia de movimiento reducido, el perro queda visible en una posición fija.

INSTALACIÓN
1. Descomprimir este ZIP.
2. Abrir la carpeta FM-radio-main.
3. Subir su contenido al repositorio GitHub, reemplazando los archivos correspondientes y conservando las carpetas.
4. Esperar la publicación de GitHub Pages.
5. Cerrar y volver a abrir la aplicación o pulsar “Nueva actualización” para limpiar la versión anterior de caché.

NOTA
No se puede garantizar literalmente cada navegador Android antiguo o modificado, pero se eligió GIF + CSS por su amplia compatibilidad. El ZIP no modifica ni publica automáticamente el repositorio.
